## ✨ Key Features

- 🐍 **Line-by-Line Python Code Visualization**  
  Watch Python scripts execute step-by-step. Inspect real-time changes to local and global variables, call stack frames, and object references in memory.

- 🧩 **Interactive DSA Problem Solver**  
  Practice classic and advanced Data Structures and Algorithms (Arrays, Linked Lists, Trees, Graphs, Dynamic Programming) with visual feedback on algorithm efficiency and state changes.

- 🧠 **Backend Memory & Pointer Insights**  
  Demystify complex data structures by observing explicit memory allocation, object dynamic binding, and pointer references under the hood.

- ⏯️ **Precision Execution Control**  
  Take control of code runtime with full play, pause, step-forward, and rewind capabilities to analyze recursion depth and nested loops at your own pace.

- 📊 **Call Stack & Scope Inspection**  
  Clearly trace function invocations, stack frames, returning values, and variable scopes to catch debugging issues faster.
